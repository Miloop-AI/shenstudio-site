# 大道传媒 Shen Studio 网站项目交接文档

最后更新：2026年8月

## 一、项目背景

大道传媒 Shen Studio 是一家位于南湾的中文媒体公司，创办人是本项目负责人的好友。内容方向覆盖硅谷科技、南湾生活、热点、财经、教育。目前已有的品牌资产是一个黑白配色的折纸风格 S 形标志，配英文名 Shen Studio。

网站的核心诉求：

- 展示播客节目（目前分发在 Spotify、Podbean、Apple Podcast 三个平台）
- 展示 YouTube 频道内容（频道已建立，但目前还没有任何影片）
- 未来会有文章内容，需要一个只有创办人本人能访问的私人后台来撰写和发布
- 展示价目表，未来希望商家可以在网站上直接查看报价并线上下单付款

### 设计原则（几轮修改后确认下来的方向）

- 不使用装饰性图形（印章、音波、虚线空状态框等已经全部拿掉），版面的高级感来自克制的排版、字级层次和留白，而不是插图或图案
- 图片依赖降到最低：整个首页只有一处图片位（Hero），目前用的是创办人自己的青蓝品牌 banner（详见第十一节），属于品牌层级的图，不需要每则内容更换。其余所有内容行都是纯文字，即使完全不更新图片，页面也不会显得单薄或破损
- 排版参考端传媒 Initium Media（theinitium.com）：每一则内容用「标签＋标题＋一句话摘要＋作者或日期」的横列呈现，不做卡片化设计

## 三、内容与栏目模型

**明确决定不使用固定主题分类**（如硅谷科技／南湾生活／热点／财经／教育这种预先规划好的分类导览），原因是创办人目前每个主题的内容量并不均衡，硬做分类导览容易出现某些分类长期空置的情况。

替代方案：

- 内容按**形式**分为播客、影片、文章三类，作为网站的主要结构
- 每则内容可以挂一个**栏目**标签（欄目 = 固定的、有名字的节目或专栏，例如她现在的播客本身可以算一个栏目），栏目字段是自由新增的，不是预先规划好的固定清单，现在只有一个栏目完全没问题，之后开新节目再加新标签即可
- 这个「不分类、用自由标签」的做法，在端传媒的真实网站上得到验证：他们的每篇文章上挂的标签可能是地区、主题、或栏目名称，混用没有固定体系

## 七、文章后台（尚未开发，仅完成需求确认）

创办人需要一个只有她自己能登入的私人写作后台，写完发布后，文章会自动出现在公开网站上；未发布的草稿任何人都看不到，包括公开网站的 API 也不会读到。

技术路线建议两个方向，尚未最终决定：

1. **Headless CMS ＋ 自定前端**（例如 Sanity ＋ Next.js）：设计自由度最高，跟目前这套完全自定的视觉风格最搭配，后台（Studio）独立部署在需要登入的网址上，跟公开网站完全分开
2. **Ghost**：专门为"播客＋文章＋电子报"这种内容型态设计的发布平台，写作界面对非技术背景的人更友好；端传媒 Initium Media 实际使用的就是 Ghost（v4 的排版参考对象），是一个真实案例的验证

## 八、价目表与线上付款

目标：商家能在网站上看到报价，并直接线上下单付款。

技术方案：用 Stripe 的 Payment Links 或 Checkout，不需要自己处理信用卡数据，符合 PCI 合规要求。

**当前进度：只做了 UI 占位，还没有接入真正的 Stripe。** 价目表页面的每个方案卡片上的付款按钮目前是虚线边框、不可点击的样式，标注"开发中"，并附一行"请透过 email 洽谈合作"的提示，避免商家点击后没有反应。

## 九、上线收费前需要确认的法律与商业前提（重要，非法律或财务建议）

以下内容需要她本人找会计师或律师确认，这里只列出需要注意的方向：

- **商业实体与收款账户**：开通 Stripe 等收款服务通常需要正式登记的商业实体（LLC 或 DBA）和对应的商业银行账户，个人账户一般不行
- **销售税**：加州对广告版位、内容合作这类"服务型"收费一般不像实体商品那样课销售税，但具体规则需要用她的会计师或加州 CDTFA 的最新指引确认
- **隐私权政策（CCPA）**：网站只要收集商家的联络或付款相关信息，作为加州网站需要有一份符合 CCPA 揭露要求的隐私权政策
- **合作条款**：建议在下单流程中附一份清楚的服务条款（业界常称 Insertion Order），讲清楚买到的到底是什么版位、什么内容形式、取消退款规则是什么
- **赞助内容揭露（FTC）**：如果商家付费换来的是一篇看起来像编辑内容的文章或节目，需要清楚标示"赞助内容"或"合作内容"字样，避免被认定为误导性广告
